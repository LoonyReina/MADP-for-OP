# MADP evaluation gateway runtime

This preview exports the existing Gateway journal, transport contracts, retained
terminal evidence and ACK lifecycle through `GatewayRuntime`. A trusted host
must provide `BundleStorePort`; no oracle or materializer is selected by Solver
input. `MemoryTransport` is a synthetic test adapter, not an NPU executor.

The concrete GitPartner adapter, Engine/TestPlan compiler, endpoint configuration,
browser accounts and service launcher are not part of this package. Reconcile
an uncertain publication under its original request identity; do not create a
replacement request merely because a response was lost.
